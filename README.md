# NA-QSP_sims

Simulations and figure-generation code for **"Non-Abelian Quantum Signal Processing"** ([arXiv:2504.19992](https://arxiv.org/abs/2504.19992)).

This repo produces the qubit-oscillator (GKP bosonic code) simulation results and all main-text and supplementary figures in the paper, including the performance of the **GCR (Generalized Composite Rotation)** and **BB1(GCR)** pulse sequences used for robust, non-Abelian quantum signal processing and modular readout of GKP qubits.

For the companion repository exploring unitary operations under realistic noise for modular readout of GKP qubits using **BB1(GCR)**, see [BB1_GCR](https://github.com/shraggy/BB1_GCR).

## Requirements

Basic Python packages for qubit-oscillator simulations:
- [QuTiP](https://qutip.org/)
- [SciPy](https://scipy.org/)
- [NumPy](https://numpy.org/)

## Repository structure

- [NA-QSP_sims.ipynb](NA-QSP_sims.ipynb) — generates the simulation data used throughout the paper (e.g. Fig. 2a/2b, Fig. 3 [BB1(GCR)], Fig. 4c, Fig. 14).
- [Paper_Figures_NA-QSP.ipynb](Paper_Figures_NA-QSP.ipynb) — loads the generated data and produces the main-text figures.
- [Paper_Data/](Paper_Data/) — `.npz` data files generated by `NA-QSP_sims.ipynb`, consumed by `Paper_Figures_NA-QSP.ipynb`.
- [Paper_Figures/](Paper_Figures/) — output figures (PDF/PNG) for the main text.
- [Supp_Figures/](Supp_Figures/) — output figures for the supplementary text.

## Usage

1. Run `NA-QSP_sims.ipynb` to (re)generate the simulation data into `Paper_Data/`.
2. Run `Paper_Figures_NA-QSP.ipynb` to plot the data into `Paper_Figures/` and `Supp_Figures/`.
